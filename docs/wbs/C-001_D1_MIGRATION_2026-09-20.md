# C-001 D1 migration implementation — 2026-09-20

Status: implementation complete; D1-local application validation pending.

## Scope

C-001 / W2-011 / CP-04 introduces the initial D1 schema in
`workers/api/migrations/0001_initial.sql`.

Created tables:

- `players`
- `player_core`
- `player_inventory`
- `recent_archive`
- `player_mutation_guards`

Created indexes:

- `idx_recent_archive_player_claimed_at`
- `idx_recent_archive_pending_sync`
- `idx_player_core_active_exploration`

## Contract mapping

`player_core` stores the authoritative `PlayerCoreSnapshot` JSON and separates
`schema_version`, `state_version`, `level`, `exp`, `gold`,
`active_exploration_id`, and `active_claim_nonce` for optimistic locking,
integrity checks, and mutation handling.

`player_inventory` stores the authoritative `PlayerInventorySnapshot` JSON and
separates its schema/state versions.

`recent_archive` stores `ExplorationArchiveEntry` JSON while separating the
fields required for per-player recency ordering and pending archive sync.
Retention remains a mutation/repository concern so the existing configurable
1–5 record policy is not hard-coded into the schema.

`player_mutation_guards` supplies the per-player guard row required by the
planned atomic mutation flow and can carry the active claim nonce.

## Validation performed

The migration was executed against an in-memory SQLite database with foreign
keys enabled.

Verified:

- all five tables are created
- all three explicit indexes are created
- representative core, inventory, archive, and mutation-guard rows insert
- invalid JSON is rejected by `json_valid`
- active exploration id / claim nonce pairing is constrained
- archive sync status / synced timestamp consistency is constrained

This is SQLite-level validation. It does not claim a Wrangler/D1-local run.

## D1-local acceptance command

From `workers/api`, after a local D1 database/binding is configured:

```sh
pnpm exec wrangler d1 migrations apply <database-or-binding> --local
```

Then verify the resulting local database contains the five tables and required
indexes before marking CP-04 complete.
